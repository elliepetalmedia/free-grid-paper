## Persistent Memory

Basic Memory is the durable memory for this repository. Use only the `free-grid-paper` memory project.

- Before work that depends on prior decisions, history, known failures, or unfinished work, search Basic Memory first; load only task-relevant context.
- Current source, tests, and Git state are authoritative for current code. Memory is for rationale, decisions, non-obvious findings, invariants, pitfalls, and handoffs.
- Update existing notes instead of creating duplicates. Save only durable information likely to matter later; never save secrets, routine logs, transient debugging, or facts obvious from the repository.
- Use structured observations and exact `[[wikilinks]]`/relations when useful.
- Before ending substantial or incomplete work, persist changed decisions, important findings, and remaining handoff state.
